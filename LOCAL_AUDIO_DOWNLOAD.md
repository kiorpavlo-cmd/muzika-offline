# Завантаження аудіо на iPhone

GitHub Pages показує застосунок, але не може самостійно завантажувати аудіо. Для цього Mac запускає локальний API. Файли зберігаються в IndexedDB медіатеки Muzika на iPhone; після завантаження їх можна слухати офлайн.

## Підключення

1. Під’єднайте iPhone і Mac до однієї мережі Wi‑Fi. Через мобільну мережу 5G iPhone не дістанеться локального сервера Mac.
2. На Mac встановіть залежності, якщо їх ще немає, і запустіть сервер з папки проєкту:

   ```sh
   brew install yt-dlp ffmpeg
   node server.js
   ```

3. У виводі Terminal знайдіть «Початкова сторінка iPhone» (на кшталт `http://192.168.0.250:3000/`) і відкрийте цю адресу в Safari на iPhone.
4. На сторінці завантажте та встановіть профіль Muzika. Потім у «Параметри» → «Загальні» → «Про пристрій» → «Довірені сертифікати» увімкніть повну довіру до «Muzika Local Audio CA».
5. Відкрийте захищене посилання продовження, показане на сторінці налаштування, і натисніть посилання для відкриття Muzika. Воно налаштовує GitHub Pages PWA на локальний API. Якщо посилання відкрило Safari, а ви слухаєте музику в Muzika з іконки на екрані «Домівка», скопіюйте посилання, відкрийте Muzika з цієї іконки → «Налаштування» → «Завантаження з Mac», вставте посилання та натисніть «Підключити сервер».
6. Завантажуйте аудіо, поки сервер на Mac запущений і iPhone залишається в тій самій Wi‑Fi мережі.

Після завантаження Mac більше не потрібен для прослуховування: аудіофайли залишаються на iPhone. Якщо зміните Wi‑Fi мережу або Mac отримає іншу локальну IP-адресу, відкрийте сторінку налаштування знову та повторно перейдіть за посиланням Muzika.

Каталог `.local-certs` містить приватний ключ і токен локального API; він не має потрапляти в Git.
