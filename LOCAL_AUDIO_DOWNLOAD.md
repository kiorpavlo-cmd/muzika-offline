# Локальне завантаження аудіо

Завантажене аудіо зберігається в локальній IndexedDB-медіатеці Muzika на телефоні. Після збереження сервер Mac більше не потрібен для прослуховування.

## Запуск на Mac

Потрібні Node.js, `yt-dlp` та `ffmpeg`:

```sh
brew install yt-dlp ffmpeg
node server.js
```

Перший запуск створить локальний центр сертифікації та серверний сертифікат у `.local-certs/`. Ця папка виключена з Git.

## Підключення iPhone

Під'єднайте Mac і iPhone до однієї Wi‑Fi мережі. Адреси сервер покаже в Terminal.

Використовуйте Muzika з локальної HTTPS-адреси Mac, а не з публічної сторінки: ця адреса дозволяє PWA безпечно отримувати аудіо від локального сервера й зберігати його в своїй офлайн-медіатеці.

1. На iPhone відкрийте адресу встановлення профілю, показану сервером, і встановіть профіль **Muzika Local Audio Server** через **Налаштування → Завантажений профіль**.
2. Увімкніть повну довіру до **Muzika Local Audio CA** в **Налаштування → Загальні → Про пристрій → Довірені сертифікати**.
3. Відкрийте захищену адресу Muzika з Terminal. Вона містить одноразовий код для першого підключення; після підключення код збережеться в захищеній cookie.
4. Додайте цю сторінку на екран «Домівка» з меню Safari.

Якщо ім'я Mac із суфіксом `.local` не відкривається, використайте HTTPS-адресу з локальною IP-адресою, яку сервер теж показує.

Після завантаження трек з'явиться у **Медіатека → Викачано** й відтворюватиметься офлайн. Сервер на Mac потрібен лише під час завантаження нового аудіо.
