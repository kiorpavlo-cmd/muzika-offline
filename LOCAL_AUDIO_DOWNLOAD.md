# Завантаження аудіо на iPhone

MP3-файли зберігаються в локальній IndexedDB-медіатеці PWA на телефоні. Після завершення завантаження Mac і тунель можна зупинити: треки залишаться доступними офлайн.

## Запуск сервера на Mac

Потрібні Node.js, `yt-dlp`, `ffmpeg` і `cloudflared`:

```sh
brew install yt-dlp ffmpeg cloudflared
node server.js
```

В іншому вікні Terminal відкрийте тимчасовий HTTPS-тунель:

```sh
cloudflared tunnel --url https://localhost:3443 --no-tls-verify
```

Скопіюйте адресу `https://….trycloudflare.com`, яку покаже команда. Токен API зберігається локально в `.local-certs/download-token`; ця папка ігнорується Git.

## Підключення PWA на телефоні

Відкрийте в PWA посилання такого вигляду, підставивши адресу тунелю й токен:

```text
https://kiorpavlo-cmd.github.io/muzika-offline/#muzika-download-server=<адреса-тунелю>&muzika-download-token=<токен>
```

Застосунок збереже налаштування з фрагмента адреси й прибере його з адресного рядка. Запити до API приймаються лише з сайту Muzika та потребують токена.

Тримайте обидва вікна Terminal відкритими, поки завантажуєте музику. Тимчасова адреса тунелю змінюється після перезапуску; для нового тунелю відкрийте PWA з новим посиланням налаштування.
