# iPod для macOS

Небольшое приложение для сканирования папки с музыкой и заполнения тегов **исполнитель, название, альбом, год, жанр и обложка**.

## Запуск

1. Запустите `run.command` в этой папке или откройте единственную сборку `~/Applications/iPod.app`.
2. Выберите папку с музыкой через меню **Файл → Выбрать папку…** или нажмите `⌘O`, затем нажмите «Сканировать».

Интерфейс — нативное окно macOS. Обработчик и Mutagen упакованы в приложение; Terminal, отдельная установка Python и Tkinter не нужны.

Если macOS покажет предупреждение, нажмите на приложение правой кнопкой мыши в Finder и выберите «Открыть». Для поиска метаданных нужен интернет.

## Использование

- Закрыть приложение можно сочетанием `⌘Q` или через меню **iPod → Quit iPod**.
- Выбор музыкальной папки доступен через меню **Файл → Выбрать папку…** и сочетание `⌘O`.
- После первого сканирования список файлов и прочитанные теги сохраняются локально. При следующем запуске список восстанавливается сразу, без повторного чтения всей медиатеки; нажмите «Сканировать», чтобы обновить его. Изменения тегов вручную и автообработка также обновляют сохранённый список.
- Кэш находится в `~/Library/Application Support/Audio Library Tagger/library_cache.json` и хранит списки максимум восьми последних медиатек.
- Индикатор сканирования расположен в заголовке «Файлы медиатеки» и остаётся видимым после завершения: он сначала показывает поиск аудиофайлов и их количество, затем — чтение тегов с текущим счётчиком `файл / всего`.
- Для ускорения чтение тегов идёт параллельно, максимум для четырёх файлов одновременно. Автообработка также больше не читает все теги повторно перед началом обработки.
- **Найти совпадение** сначала проверяет аудио в Shazam через ShazamKit, даже если теги и имя файла пустые. Для результата Shazam название, исполнитель и жанр берутся из Shazam; недостающие альбом и год дополняются по Apple Music ID трека, обложка загружается из Shazam с резервом на каталог Apple Music. Результат с незаполненными тегами (исполнитель, название, альбом, год или жанр) нельзя записать. Если Shazam не находит трек или сервис недоступен, приложение переходит к AcoustID, MusicBrainz и каталогу Apple Music. Выберите полный результат и нажмите «Записать теги и обложку».
- Поиск привязан к выбранному треку: при выборе другой песни текущий запрос и фоновый поиск обложки отменяются, а запоздавшие результаты не показываются.
- Ответы поиска сохраняются в `~/Library/Application Support/Audio Library Tagger/lookup_cache.json` на 30 дней. Повторный поиск того же неизменённого файла открывается из кэша. MusicBrainz вызывается с интервалом и повторяет запрос при временной ошибке сервиса.
- При выборе трека приложение сначала показывает обложку, уже встроенную в аудиофайл. Если её нет, оно ищет подходящую обложку онлайн и показывает её для выбранного трека.
- Выберите трек и нажмите `Пробел`, чтобы начать или приостановить воспроизведение. Кнопка «Воспроизвести» в панели тегов делает то же самое. Во время ввода текста пробел остаётся обычным пробелом.
- Нажмите `⌘A`, чтобы выделить все треки в списке. В полях ввода эта комбинация выделяет текст.
- **Автообработка папки** ищет все композиции и записывает только достаточно уверенные совпадения. Автообработка заполняет пустые поля и не стирает заполненные значения. При неоднозначном совпадении файл пропускается.
- Перед изменением каждого файла создаётся его копия в `~/Library/Application Support/Audio Library Tagger/backups/`. Это позволяет вернуть исходный файл вручную.
- Поддерживаются распространённые форматы, которые умеет читать Mutagen: MP3, M4A/MP4, FLAC, Ogg, Opus, WAV, AIFF, WMA и другие. Встраивание обложки зависит от формата; программа покажет предупреждение, если формат не принимает её.

## Распознавание по звучанию

Для основного поиска используется ShazamKit: приложение локально создаёт подпись короткого фрагмента MP3 и сверяет её с каталогом Shazam. Чтобы включить каталог Shazam, активируйте ShazamKit для App ID `com.codex.audiolibrarytagger.app` в Apple Developer. Если Shazam не отвечает или не распознаёт запись, резервный поиск использует встроенный ключ AcoustID и Chromaprint (`fpcalc`). Если перенести приложение на другой Mac без Chromaprint, установите его командой `brew install chromaprint`.

ShazamKit обрабатывает аудио на этом Mac и сверяет аудиоподпись с каталогом Shazam; исходный MP3 не загружается как файл. При резервном поиске в AcoustID отправляются фингерпринт и длительность. Дополнительные метаданные ищутся в MusicBrainz и Apple Music; обложки для записи в файл загружаются из Cover Art Archive. Жанр записывается, когда он есть в каталогах; для многих записей он может отсутствовать. Автообработка обращается к MusicBrainz последовательно.

## Важно

Программа распознаёт звук через ShazamKit и AcoustID: имя файла и заполненные теги для такого поиска не нужны. Автоматическая обработка сохраняет только совпадения выше порога уверенности, но перед первым большим запуском попробуйте её на небольшой копии папки и проверьте результат.

`run.command` открывает единственную сборку `~/Applications/iPod.app`.
