# Музика

Мобільний офлайн‑орієнтований музичний вебзастосунок. Інтерфейс відтворює навігацію й темну тему з наданих зображень; комп'ютерний макет можна додати окремо.

## Що вже працює

- PWA встановлюється на телефон із браузера.
- Оболонка застосунку кешується і відкривається без мережі.
- Під час запуску застосунок перевіряє сервіс‑воркер і завантажує оновлені файли, якщо вони є. Без мережі використовує останню збережену версію.
- Музичні файли можна додати з пристрою. Вони зберігаються локально в браузері та відтворюються офлайн.
- Пошук, улюблені пісні, мініплеєр і навігація працюють локально.
- Профіль можна під'єднати через Google; музика при цьому залишається на пристрої.
- `Muzika.mobileconfig` додає ярлик застосунку на головний екран iPhone або iPad і використовує іконку проєкту.

Каталог у демонстрації — зразок інтерфейсу без аудіозаписів. Щоб відтворювати музику, додайте власні аудіофайли через **Медіатека → +**. Назву й виконавця можна вказати у назві файлу як `Виконавець — Пісня.mp3`.

## Локальний запуск

Сервіс‑воркери працюють через HTTPS або `localhost`. У папці проєкту виконайте:

```sh
python3 -m http.server 8000
```

Потім відкрийте `http://localhost:8000`.

## Публікація на GitHub Pages

У репозиторії вже є GitHub Actions workflow для публікації статичного застосунку. Після push гілки `main` відкрийте **Settings → Pages** та виберіть **GitHub Actions** як джерело. Публічна адреса матиме вигляд `https://<користувач>.github.io/<репозиторій>/`.

Локальні аудіофайли не завантажуються в GitHub і не синхронізуються між пристроями.

Профіль ярлика відкриває `https://kiorpavlo-cmd.github.io/muzika-offline/`. Після публікації його можна завантажити з налаштувань застосунку або за адресою `https://kiorpavlo-cmd.github.io/muzika-offline/Muzika.mobileconfig`.

## Google-вхід

Щоб увімкнути вхід, створіть OAuth 2.0 Web Client ID у Google Cloud Console, додайте `https://kiorpavlo-cmd.github.io` до Authorized JavaScript origins і вставте Client ID у `content` тегу `<meta name="google-client-id">` у `index.html`. Не додавайте Client Secret до статичного сайту. Профіль Google зберігається локально; синхронізація аудіофайлів не налаштована.
