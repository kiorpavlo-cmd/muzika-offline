# iPod — спільний проєкт Mac та iPhone

У цій папці поєднані два застосунки з однаковою назвою та піктограмою:

- `iPod.app` — готовий застосунок macOS для сканування аудіотеки, пошуку та запису тегів і обкладинок.
- PWA у `index.html` — офлайн-медіатека iPhone; профіль `iPod.mobileconfig` встановлює її як ярлик iPod з піктограмою Mac.
- `server.js` та `Start iPod Sync.command` передають музику з папки Mac до iPhone через локальну мережу Wi‑Fi.
- `macOS/source/` містить вихідний код і інструкції для Mac-застосунку.

## Підготувати музику на Mac

1. Відкрийте `iPod.app`.
2. Виберіть папку з музикою та натисніть «Сканувати». Tagger зберігає вибрану папку й індекс тегів локально.
3. Для запису знайдених даних виберіть запис у вікні результатів і натисніть «Записать теги и обложку». Зміни записуються в оригінальний аудіофайл.

## Синхронізувати Mac → iPhone

1. На Mac і iPhone під’єднайтеся до однієї мережі Wi‑Fi.
2. У цій папці двічі клацніть `Start iPod Sync.command`. Не закривайте Terminal, доки триває синхронізація. Перший запуск створить локальний сертифікат.
3. На iPhone відкрийте надруковану в Terminal адресу `http://<адреса Mac>:3000/`. Завантажте та встановіть профіль сертифіката. Потім у «Параметри» → «Загальні» → «Про пристрій» → «Параметри довіри сертифікатам» увімкніть повну довіру до `iPod Local Audio CA`.
4. Повторно відкрийте захищену адресу `https://<адреса Mac>:3443/setup`. Вона створить посилання підключення з одноразовим для цієї установки секретом.
5. Відкрийте PWA iPod на iPhone → «Налаштування» → вставте повне посилання зі сторінки Mac → «Підключити Mac». Якщо сайт ще не встановлено, спершу відкрийте GitHub Pages, виберіть «Поділитися» → «На екран Домівка».
6. Натисніть «Синхронізувати музику», позначте нові або змінені пісні та завантажте їх. Після завантаження треки залишаються в офлайн-медіатеці iPhone й відтворюються без Mac.

Синхронізація одностороння — з папки Mac на iPhone. Оригінали на Mac не змінюються під час передавання. Сканування та редагування тегів виконує iPod.app; PWA отримує аудіофайли й теги з кеша Tagger. Щоб перенести оновлені теги, повторно проскануйте медіатеку на Mac і синхронізуйте змінені файли.

## Профіль iPhone

`iPod.mobileconfig` встановлює ярлик iPod на головний екран і містить PNG-піктограму, підготовлену з тієї самої іконки, що входить до `iPod.app`. Профіль сертифіката Mac (`iPod-Local-Audio-CA.mobileconfig`) окремий: він потрібен лише для захищеного з’єднання під час синхронізації.

Після редагування PWA, щоб зміни з’явились за адресою GitHub Pages, опублікуйте оновлену гілку `main`. Автоматичне опублікування не виконується цією локальною збіркою.
