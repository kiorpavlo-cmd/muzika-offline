# iPod — спільний проєкт Mac та iPhone

У цій папці поєднані два застосунки з однаковою назвою та піктограмою:

- Єдина актуальна збірка macOS — `~/Applications/iPod.app`: сканування аудіотеки, пошук і запис тегів та обкладинок.
- PWA у `index.html` — офлайн-медіатека iPhone; профіль `iPod.mobileconfig` встановлює її як ярлик iPod з піктограмою Mac.
- `server.js` та `Start iPod Sync.command` передають музику з папки Mac до iPhone через локальну мережу Wi‑Fi.
- `macOS/source/` містить вихідний код і інструкції для Mac-застосунку.

## Підготувати музику на Mac

1. Відкрийте `~/Applications/iPod.app` або запустіть `macOS/source/run.command`.
2. Виберіть папку з музикою та натисніть «Сканувати». Tagger зберігає вибрану папку й індекс тегів локально.
3. Для запису знайдених даних виберіть запис у вікні результатів і натисніть «Записать теги и обложку». Зміни записуються в оригінальний аудіофайл.

## Синхронизация Mac → iPhone

Mac запускает локальный HTTPS-сервер вместе с iPod. Для синхронизации через интернет используется бесплатный личный план [Tailscale](https://tailscale.com/pricing) и приватный Tailscale Serve. Установите Tailscale на Mac и iPhone, войдите в один личный tailnet и оставьте Tailscale включённым на телефоне. Включите MagicDNS и HTTPS-сертификаты в настройках tailnet. **Funnel не включайте:** Serve доступен только устройствам в tailnet. Имя tailnet и устройств публикуется в открытом журнале сертификатов; выберите нейтральные имена, если это важно для приватности. [Инструкция Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve), [настройка HTTPS](https://tailscale.com/docs/how-to/set-up-https-certificates).

Отдельная точка доступа не нужна: Mac может использовать интернет через точку доступа iPhone. Mac должен быть включён, а iPod на Mac и Tailscale на обоих устройствах — запущены.

Первое подключение после настройки Tailscale: на Mac нажмите «Копировать» у ссылки подключения; на iPhone откройте установленный iPod, нажмите «Подключить с буфера обмена» и подтвердите системную вставку iOS. iPod сохранит ссылку и сразу откроет список синхронизации. Нажмите «Загрузить выбранные» — новые и изменённые песни отмечены автоматически. Это до пяти действий, считая копирование ссылки и подтверждение вставки; установка и вход в Tailscale выполняются заранее.

Повторная синхронизация: открыть iPod → нажать на главной странице «Синхронизировать новые песни с Mac» → «Загрузить выбранные». Это три нажатия, включая запуск iPod.

Если Tailscale не установлен или Serve не настроен, приложение оставляет локальный HTTPS-вариант. Для него передайте профиль через AirDrop и вручную включите полное доверие к `iPod Local Audio CA` в настройках iOS: «Настройки» → «Основные» → «Об этом устройстве» → «Доверие сертификатам». iOS требует этот системный шаг для локального сертификата.

AirDrop также позволяет импортировать выбранные аудиофайлы без сервера и профиля. На Mac выделите песни и нажмите «AirDrop выбранных». На iPhone нажмите на главной странице iPod «Импортировать музыку из AirDrop или Файлов» и выберите полученные файлы.

## Профіль iPhone

`iPod.mobileconfig` встановлює ярлик iPod на головний екран. Для Tailscale посилання на підключення передається з Mac у буфер обміну; профіль сертифіката не потрібен. Для локального HTTPS застосовується окремий профіль із CA-сертифікатом.

## Перевірки

Запустіть `node --test tests/sync.test.js`. Тест перевіряє єдиний HTTPS-сервер, авторизацію, список пісень і профіль AirDrop.

Після редагування PWA, щоб зміни з’явились за адресою GitHub Pages, опублікуйте оновлену гілку `main`. Автоматичне опублікування не виконується цією локальною збіркою.
